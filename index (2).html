How to Host on GitHub Pages in 2 Minutes

  1. Create a new GitHub repository (e.g., family-charts).
  2. Save this single HTML file as index.html and upload it to the repo.
  3. Go to Settings → Pages, select Deploy from branch (main), and save.
  4. Bookmark your new GitHub Pages URL on your phone or laptop! Log points here, click Copy CSV, and paste into progress_log.csv in your repo whenever you want to back up or sync across devices.
